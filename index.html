Project 01

Telegram AI 翻译 Bot

将翻译 Agent 从单次对话工具延伸到即时通讯场景：用户在 Telegram 发送中文或英文消息，系统通过 n8n 触发 Gemini 处理，并把翻译结果自动回复给对应用户。

n8n Telegram Bot API Google Gemini Prompt 规则
查看完整项目页
效果证据：网络用语与中文成语被转化为自然表达，并输出语气与习语判断。
Telegram 消息 Telegram Trigger AI Agent + Gemini Telegram 自动回复

问题与目标

普通翻译工具往往脱离用户真实聊天环境，也容易忽略习语和语气。这个原型验证“聊天界面里的自动翻译 Agent”是否能在不切换工具的情况下，完成语言识别、习语处理、语气保留和自动回复。

Agent 规则

语言判断中文输入翻译为英文，英文输入翻译为简体中文。
习语处理先理解含义，再寻找目标语言中的自然表达，避免逐字硬翻。
语气保留识别讽刺、沮丧、玩笑、无奈等真实语气，并在输出中标注。
边界处理遇到非中英文输入时，说明仅支持中文与英文。

测试设计

  • 简单中文到英文、简单英文到中文。
  • 英文习语压力测试，例如 workplace idioms。
  • 中文成语压力测试，例如“大意失荆州”。
  • 网络用语、混合语言、第三语言等边界测试。

产品思考

  • 聊天场景需要低摩擦，Bot 比网页工具更接近用户原有行为。
  • 语气与习语标注让输出更可判断，也方便后续评估。
  • 下一步可增加语言选择、反馈按钮、术语表和失败日志。

Project 03

智能邮件日程助手 Agent

使用 Make.com 集成 Gmail、Google Gemini 与 Google Calendar，验证 AI 是否能从邮件中识别任务、抽取结构化字段，并在有效信息充分时自动创建日历事件。

Make.com Gmail Gemini Google Calendar
查看完整项目页 查看 Make 公开场景

验证结果

测试邮件10 封
有效事项识别 4 个
执行结果创建 4 个 Google Calendar 事件
过滤规则没有任务时输出 ignore，避免误创建事件。
Gmail 搜索邮件 Gemini 判断任务 字段抽取与过滤 Calendar 创建事件

问题与目标

邮件里的会议、截止日期和待办事项分散且格式不统一。这个原型验证是否可以让 AI 先判断邮件是否包含明确任务，再将任务名、开始时间、结束时间和详情转成日历事件。

执行边界

  • 非任务类邮件不进入日历创建流程。
  • 信息不足时优先过滤或等待确认。
  • 后续可增加人工确认、失败日志和模糊时间处理。
