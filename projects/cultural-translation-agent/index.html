Project 02 / Claude Projects + Agent Design

Claude 文化翻译 Agent

这个 Agent 聚焦跨文化语义翻译：不只把句子换成另一种语言，而是先判断成语、习语、讽刺、语气和文化语境，再输出更自然的目标语言表达。

查看 Claude 分享链接
Agent 行为设计 Meta-Prompting Prompt Engineering 跨文化沟通
效果证据：中文成语“塞翁失马”先被解释为语义，再转为英文与 Hindi 表达。

Problem Framing

翻译难点不在字面，而在语境

用户问题

普通翻译容易丢失文化含义

成语、习语和讽刺表达经常不能逐字翻译。如果只追求词汇对应，目标语言用户可能看懂了字面，却误解了真实语气和意图。

产品挑战

AI 需要稳定的判断路径

同一句话可能包含语言、文化、情绪和隐含意图。Agent 的关键不是“会翻译”，而是把判断步骤和输出边界设计清楚。

产品判断：跨文化翻译的质量取决于含义识别、语气判断和目标语言表达是否自然。Agent 应先理解语义，再选择表达，而不是逐字替换。

Agent Building Method

从 prompt 到 Agent 行为设计

1. Research梳理习语、成语和语气翻译难点。
2. Meta-Prompting让 AI 辅助生成 Agent 指令草案。
3. Iterate测试、批判、决策并修改规则。
4. Deploy沉淀到 Claude Projects，形成可复用 Agent。

Agent Framework

角色、目标、技能、规则与反馈回路

角色 / 目标

跨文化语义翻译助手

目标是保留含义、语气和文化隐含信息，而不是追求逐字对应。

技能

条件判断步骤

先检测语言和习语，再识别语气类型，最后按目标语言习惯表达。

规则 / 反馈

约束稳定输出

不添加原文没有的信息；通过测试和失败样例持续修订 Agent 指令。

Iteration Logic

测试、批判与决策日志

环节做法产品意义
测试使用基础习语、多重习语、讽刺表达和多语言输入观察输出。用可复现样例判断 Agent 是否稳定，而不是只看一次结果。
批判让 AI 直接指出指令中的模糊规则、缺失边界和可能失败场景。把 prompt 迭代从“感觉不好”变成可解释的问题清单。
决策保留有效规则，修改造成不一致输出的规则。体现产品迭代中的取舍，而不是无边界堆功能。
部署将最终指令放入 Claude Project。让一次性对话沉淀为可复用 Agent。

Evidence

效果样例

中文成语：解释“塞翁失马”的文化含义，再映射为英文和 Hindi 表达。
英文讽刺表达：识别“不可能发生”的语气，再转为简体中文和 Hindi。
Hindi 成语：处理 Devanagari 输入，并解释为快速逃跑或突然消失。

Product Thinking

用户价值与风险边界

可转化场景
  • 留学生跨文化沟通辅助。
  • 国际团队邮件、聊天和文档表达润色。
  • 客服与运营场景中的多语言语气适配。
  • 品牌本地化内容审核与文化风险提示。
Responsible AI
  • 不把输出作为法律、医疗、移民等高风险文本的最终译文。
  • 遇到含义不确定或文化语境不足时，应提示不确定性。
  • 避免添加原文没有的事实、评价或身份判断。
  • 对冒犯性、歧视性或敏感表达保留人工复核空间。
